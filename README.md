# Cafeneaua Ta - Pagina Web

Aceasta este o pagină web de prezentare a unei cafenele fictive, "Cafeneaua Ta". 
Scopul acestui proiect este de a demonstra un design web modern, folosind HTML și Tailwind CSS pentru a crea o experiență atractivă pentru utilizatori. 
Pagina include informații despre cafenea, o galerie foto, un meniu recomandat și locația cafenelei pe Google Maps.

## Tehnologii Folosite
- **HTML5**: Structura paginii.
- **Tailwind CSS**: Framework pentru stilizarea paginii.
- **Google Fonts**: Fonturi pentru textul paginii.
- **Google Maps Embed**: Încadrarea locației cafenelei pe hartă.

## Structura Paginii

Pagina este împărțită în mai multe secțiuni, fiecare cu un rol specific:

1. **Hero Section**: Imaginea de fundal a cafenelei, cu un text introductiv și o descriere scurtă a cafenelei.
2. **Despre Noi**: Secțiune care detaliază filosofia cafenelei, atmosfera și produsele oferite.
3. **Galerie Foto**: O serie de imagini cu diverse produse și interioare ale cafenelei.
4. **Meniu Recomandat**: O listă de băuturi și deserturi populare, fiecare cu o scurtă descriere.
5. **Locație și Contact**: Informații despre locația cafenelei și programul de lucru, cu integrarea unui iframe Google Maps.
6. **Footer**: Informații legale și drepturi de autor.
